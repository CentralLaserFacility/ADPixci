# Third Party Licenses

## EPIX® XCLIB® Library

This repository includes redistributable components from the **XCLIB** Library provided by **EPIX Inc.**, used to interface with EPIX® PIXCI® series frame grabbers and frame generators.  

The following files from the XCLIB Library are present in this repository under the pixciSupport directory to enable application development:

- Dynamic link libraries (`.dll`)  
- Import libraries (`.lib`)  
- Header files (`.h`)  

According to EPIX Inc.’s published licensing statement for XCLIB:

> *"Licensing permits royalty free inclusion of library routines into applications using EPIX® PIXCI® series frame grabbers or frame generators."*  
> — [EPIX XCLIB product page](https://www.epixinc.com/products/xclib.htm)
